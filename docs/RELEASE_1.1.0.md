# 1.1.0 · 背景与莫奈取色

应用版本：`1.1.0+3`。本说明记录新增功能及实现范围；构建是否完成、具体源码提交和安装包校验值，以对应 GitHub Actions 运行与 Release 内的 `CI_BUILD_REPORT.md` 为准。

## 使用方式

1. 打开「我的 → 背景与配色」。
2. 选择经典底色、晨曦 / 森林 / 暮色渐变，或从相册选择照片。
3. 在「主题配色」选择「背景莫奈取色」，让按钮、标签和主题色随当前背景变化；也可使用系统配色或八种自选主题色。
4. 调整阅读柔化强度，使背景适合阅读。页面顶部提供实时外观预览，浅色 / 深色模式仍由原有外观设置控制。

手机与平板共用这些设置；窄屏背景选项换行排列，宽屏使用更多列。删除保存的照片或恢复默认设置可在同一页面完成。

布局预览：[手机设置](previews/appearance-phone.png) · [平板深色主题](previews/monet-tablet.png)。两张预览使用合成示例内容。

## 本地图片与配色

- 相册选择使用系统图片选择器；取消选择或处理失败时保留已有背景。
- 导入照片归一化为 PNG，最长边限制为 1600 像素，并去除原照片元数据。背景文件位于应用私有目录，不会上传至校园墙或其他服务。
- 提色样本最长边为 112 像素，使用 Material Color Utilities 的 `QuantizerCelebi` 和 `Score` 在后台 isolate 量化与选色。保存提取到的源色种子，再通过 `ColorScheme.fromSeed` 分别生成浅色与深色 Material 3 配色。
- 内置渐变使用对应的预设色种子。系统配色在 Android 12+ 使用系统提供的动态配色，其余平台使用默认配色；背景莫奈取色和手动选色可在 Android / iOS 使用。
- 背景、配色模式、主题色和阅读柔化强度在本机持久化。照片以相对文件名保存，启动时重新解析应用目录；文件缺失时回退到经典背景。Android 在选择器打开期间被系统回收后，会尝试恢复选图结果。
- iOS 工程包含照片访问用途说明，继续保留 iOS 26 Liquid Glass 和旧系统材质回退。

## 绘制与验证范围

背景位于导航器下方的单独静态绘制层，列表滚动不会移动整张背景；图片解码尺寸受限，量化只在导入时运行。新增功能不使用全屏实时模糊，阅读柔化调整复用已生成的主题。系统高对比度模式使用实色背景以保持可读性。

本版新增外观持久化、损坏配置修复、照片取消 / 失败处理、图片归一化与提色、背景 / 配色切换、重置及手机 / 平板布局的测试。测试不代替系统相册、内存回收和真机性能验证；尚未据此验证具体设备上的 60 / 120 fps、功耗或 iOS Liquid Glass 实机合成表现。

## 构建与下载

推送后沿用仓库内 Android / macOS iOS 构建和发布流程。三个平台构建任务成功后，发布工作流会校验产物结构、iOS 版本和 Android 签名，再创建对应版本的 GitHub Release。相同版本已发布的产物不会自动覆盖。

[最新正式版下载](https://github.com/Jay-Void-BA/fxlovewall-flutter/releases/latest)包含 Android APK、iOS 未签名 IPA、模拟器包和 SHA-256 校验文件。实际发布版本以页面标签为准。Google Drive 交付沿用原文件夹组织，具体同步结果另行核对。

Android CI 使用测试签名，不同运行生成的 APK 不保证能覆盖安装旧版；连续发行应配置固定发行签名。iOS IPA 仍需有效证书和相应配置签名后才能安装，模拟器包供 macOS / Xcode 使用。
